A. Pre-Test

1. Jelaskan kedudukan CSS dalam pemrograman web.

CSS (Cascading Style Sheets) merupakan bahasa stylesheet yang digunakan untuk mengatur dan memperindah tampilan halaman web. Dalam pemrograman web, CSS memiliki kedudukan sebagai bagian yang mengatur aspek visual atau desain dari sebuah website, sedangkan HTML digunakan untuk menyusun struktur dan isi halaman web. CSS berfungsi untuk mengatur berbagai elemen tampilan, seperti warna tulisan, jenis dan ukuran huruf, warna latar belakang, jarak antar elemen, ukuran gambar, garis tepi, serta tata letak halaman. Dengan adanya CSS, tampilan website menjadi lebih menarik, rapi, terstruktur, dan mudah dibaca oleh pengguna

2. Berikan masing-masing satu contoh penggunaan css selektor

  • Element Selector : Element Selector adalah selector yang digunakan untuk memilih elemen HTML berdasarkan nama tag-nya. Pengaturan CSS akan berlaku untuk semua elemen yang menggunakan tag tersebut.

    p {

    color: blue;

    font-size: 18px;

    }

  • ID Selector: ID Selector adalah selector yang digunakan untuk memilih elemen HTML berdasarkan atribut id yang dimilikinya. Selector ini ditandai dengan tanda pagar (#) sebelum nama ID. Biasanya, ID digunakan untuk memberikan identitas khusus pada satu elemen HTML.

    • #judul {

    color: pink;

    text-align: center;

    }

  • Universal Selektor : Universal Selector adalah selector yang digunakan untuk memilih seluruh elemen HTML yang terdapat dalam halaman web. Selector ini ditandai dengan simbol bintang (*).

    • * {

    font-family: Arial;

    color: black;

    }

  • Class Selector : Class Selector adalah selector yang digunakan untuk memilih elemen HTML berdasarkan nama class yang diberikan. Selector ini ditandai dengan tanda titik (.) sebelum nama class. Satu class dapat digunakan oleh beberapa elemen HTML sekaligus.

    • .kartu {

    background-color: lightgray;

    color: black;

    padding: 10px;

    }
